ParallelogramP = 2(b + c)A = bh

RhombusP = 4sA = bh = (d₁ × d₂) ÷ 2
KiteP = 2(a + b)A = (c × d) ÷ 2
ObjectSurface areaVolume
CubeSA = 6s²V = s³
Rectangular prismSA = 2(lw + lh + wh)V = lwh
Triangular prismSA = bh + (a+b+c)LV = (bh ÷ 2) × L
CylinderSA = 2πr² + 2πrhV = πr²h
